# ردیاب سیگنال (Signal Tracker)

1. Android Studio (Koala یا جدیدتر) → File ▸ Open → همین پوشه.
2. صبر کنید Gradle Sync تمام شود (Gradle 8.7 و JDK 17 که با Studio می‌آید).
3. گوشی را با USB وصل کنید (USB debugging روشن) و Run ▶ بزنید.
   برای فایل APK: Build ▸ Build APK(s).
4. در اپ ⚙️ را بزنید، توکن ربات را وارد کنید. ربات باید ادمین کانال باشد.

نکته: ربات فقط یک مصرف‌کنندهٔ getUpdates می‌تواند داشته باشد؛ روی ربات Webhook نگذارید.
